# 使用指南

## 基本流程

1. 在 Zotero PDF 阅读器中选中英文单词或短语。
2. 点击 Word Learning 插件入口。
3. 在“添加单词”页面检查词条。
4. 点击 LLM 补全。
5. 检查并修改生成内容。
6. 保存词条。
7. 在“复习”页面开始复习。

## 页面说明

- 添加单词：用于录入新词条。
- 单词卡片：用于浏览和修改当前词条。
- 全部词汇：用于查看、搜索、排序完整词库。
- 复习：用于三种题型混合复习。
- 设置：用于配置 LLM、思考强度和数据库路径。

## 复习规则

每个单词包含三种题型：

1. 单词选择释义。
2. 单词 + 例句选择释义。
3. 根据音标、发音和释义拼写单词。

一个单词必须三种题型全部正确，进度才会 +1。

答错的题型会重新进入当前随机池，已经答对的题型不会重置。
